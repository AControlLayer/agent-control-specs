# AControlLayer draft specifications — withdrawn

> **Withdrawn.** Every draft specification published on this site was withdrawn on August 8, 2026. They are kept for historical reference only. None of them is a standard, and no product conforms to them.

AControlLayer published these drafts in 2025 and 2026 for community feedback. A review found that established standards already cover each of their subjects more completely, so the drafts were withdrawn rather than developed further. No successor is planned.

Our current work aligns with the OWASP Agent Control Standard (ACS) draft rather than these specifications.

## Withdrawn drafts

| Draft | Title | Status | Already covered by |
|-------|-------|--------|--------------------|
| [SPEC-0](/docs/SPEC-0) | Specification Process | Withdrawn | — governed only the drafts below |
| [AIP-1](/docs/AIP-1) | Agent Identity Protocol | Withdrawn | SPIFFE, IETF WIMSE |
| [ADP-1](/docs/ADP-1) | Agent Data Protocol | Withdrawn | OpenTelemetry, W3C Trace Context |
| [PVS-1](/docs/PVS-1) | Policy Verdict Schema | Withdrawn | XACML 3.0, OpenID AuthZEN |
| [CTX-1](/docs/CTX-1) | Capability & Trust eXtensions | Withdrawn | SPKI (RFC 2693) |

A proposed revision, PVS-2, was withdrawn with them. See [the withdrawal record](/docs/README) for details.

## Validators

The interactive validators and the `/api/validate` endpoints that used to be on this site have been removed. They checked data against withdrawn drafts, so a passing result meant nothing.
